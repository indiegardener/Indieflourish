# Indieflourish

An open-source, non-profit Progressive Web App (PWA) dedicated to solving the loneliness epidemic and fostering genuine, values-first human connections—free from predatory, swipe-driven monetization mechanics.

## Tech Stack & Architecture
* **Frontend:** Vanilla HTML/CSS/JavaScript PWA (Mobile-first, installable to home screen).
* **Backend & Database:** Supabase (PostgreSQL, Row Level Security, Real-time Auth).
* **Hosting & Deployment:** Vercel (Zero-cost global edge routing and SSL).

## Core Features
* **Values & Lifestyle Questionnaire:** Transparent compatibility metrics based on shared choices and weights.
* **Anti-Ghosting Mechanics:** Hard limits on active chats to encourage deep, deliberate conversation over superficial volume.
* **Radical Accessibility:** ₹0 operational cost, open-source, and accessible directly via custom domain or PWA installation.
